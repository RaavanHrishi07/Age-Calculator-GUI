# Age Calculator GUI

A simple desktop application built with Python and Tkinter that calculates a person's age from their date of birth.

## Features

- Simple and user-friendly graphical interface
- Calculates age based on the current date
- Validates the entered date
- Prevents future birth dates
- Displays clear error messages for invalid input
- Lightweight and easy to run

## Technologies Used

- Python 3
- Tkinter
- datetime

## Requirements

- Python 3.x

Tkinter and datetime are included with Python's standard library, so no additional packages are required.

## How to Run

1. Download or clone this repository.
2. Open the project folder in a terminal.
3. Run the following command:

```bash
python age_calc_gui.py
```

The Age Calculator window will open.

## How to Use

1. Enter your name.
2. Enter your birth year.
3. Enter your birth month.
4. Enter your birth day.
5. Click **Calculate Age**.
6. Your calculated age will be displayed.

The application validates the entered date and prevents dates in the future.
